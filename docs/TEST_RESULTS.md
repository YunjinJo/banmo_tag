# banmo_tag 테스트 결과

버전마다 테스트를 돌린 결과를 기록합니다. 최신 결과가 맨 위에 옵니다.

- 무엇을 테스트하는지는 [TEST_CASES.md](TEST_CASES.md)를 보세요.

## 기록하는 방법

1. 릴리스할 코드에서 실행합니다. 보통 `npm run bump` 로 버전을 올린 `release/vX.Y.Z` 브랜치입니다.

   ```powershell
   npm run test:report -- --firefox --write
   ```

   - 자동 검사 결과가 이 문서 맨 위에 `## [vX.Y.Z]` 로 들어갑니다.
   - 같은 제목이 있으면 새 결과로 바뀝니다.
   - 릴리스 전 코드는 `## [Unreleased]` 로 기록됩니다.
2. 결과 아래 **수동 확인** 표를 채웁니다. 표기는 다음과 같습니다.
   - ✅ 통과
   - ❌ 실패 (메모에 증상)
   - ➖ 이번에 해당 없음
   - 빈칸: 아직 안 함
3. 실패가 있으면 고친 뒤 다시 실행합니다. 알려진 문제로 두고 릴리스하는 경우에는 메모에 이유를 적습니다.
4. 이 문서도 릴리스 PR 에 함께 커밋합니다.
