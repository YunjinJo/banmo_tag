# 📝 banmo_tag 패치 노트 (Changelog)

이 문서는 banmo_tag 크롬 확장 프로그램의 버전별 기능 추가, 변경, 버그 수정 내역을 기록하는 공식 패치 노트입니다.
각 버전의 변경 내역은 연관된 테스트 케이스([TEST_CASES.md](TEST_CASES.md)) 및 자동화 테스트 러너([run-tests.ps1](../tests/run-tests.ps1), [test-runner.html](../tests/test-runner.html))와 1:1로 매핑되어 검증됩니다.

## [Unreleased]

> 아직 릴리스하지 않은 변경 사항입니다. 새 버전을 릴리스할 때 `npm run bump -- X.Y.Z` 를 실행하면 이 항목이 그 버전의 내용이 됩니다.

### 🚀 Added (새로운 기능)
- **팝업 [설정] 창 (⚙ 버튼) — 배지 순서와 타임라인 배지 표시 (`popup.html`, `popup/settings.js`, `popup/popup.css`, `shared/list-data.js`, `shared/badges.js`, `content.js`, `styles.css`)**
  - **배지 순서**: 리스트의 우선순위를 직접 정합니다. 위에 있는 리스트의 배지가 이름 옆에 먼저 붙고, 배지가 넘치면 아래쪽 리스트부터 `+N` 으로 묶이며, 강조 리스트가 여럿이면 가장 위 리스트의 색 띠가 보입니다. ▲ ▼ 버튼(키보드로도)이나 끌어서 옮기고, [이름순으로 되돌리기]로 되돌립니다. 순서는 리스트마다 `priority` 로 저장되어 이름을 바꾸거나 멤버를 다시 가져와도 남고, 순서를 정한 뒤 새로 가져온 리스트는 맨 뒤에 붙습니다. 리스트 표의 정렬에도 **배지 순서**를 더했습니다.
  - **타임라인 배지 표시** (`displaySettings`): 보일 배지 수(1–10개 또는 모두, 넘치면 `+N`), 긴 이름 줄이기(…) 켬/끔과 줄일 길이(약 6–20글자), 배지 모양(둥글게 / 각지게), 인용 트윗 작성자 배지 켬/끔, 흐리게 정도(약하게 / 보통 / 진하게). 바꾸면 X 탭을 새로고침하지 않아도 바로 다시 그립니다.
  - **미리보기**: 모든 리스트에 속한 사람의 트윗(인용 트윗 포함)과 흐리게 리스트 멤버의 트윗을 타임라인과 같은 함수·스타일(`addBadges`, `styles.css`)로 그려 보여 줍니다. 팝업 안의 배지(리스트 표·설정 창)도 고른 배지 모양·흐리게 정도를 따릅니다.
  - 백업: 내보내기 파일에 배지 순서와 표시 설정이 들어가고, [덮어쓰기]로 복원합니다. [병합]은 지금 순서를 정해 두었으면 파일에만 있는 리스트를 맨 뒤에 붙입니다.
  - 팝업 [도움말] 탭에 **설정 (⚙)** 묶음을 더했습니다.
  - 테스트: 단위(배지 순서 정렬·옮기기·되돌리기, 표시 설정 검증, 배지 묶기, 백업), E2E(설정 창 열기·닫기·포커스, ▲ ▼ · 끌어서 옮기기, 이름순으로 되돌리기, 표시 설정 저장·미리보기, 타임라인에 배지 순서·표시 설정 반영), 실제 Firefox 확인을 추가했습니다.
- **컴퓨터에 설치된 폰트에서 고르기 (`popup/font-dialog.js`, `popup/badge.js`, `popup/sheet.js`, `shared/badges.js`)**: 배지 폰트 목록 맨 아래에 **[설치된 폰트에서 고르기…]** 를 추가했습니다(파이어폭스: [다른 폰트 직접 입력…]). [기본 스타일] 탭의 공통 설정과 리스트 설정 창 모두에서 쓸 수 있습니다.
  - **크롬·엣지**: 이 컴퓨터에 설치된 폰트(`window.queryLocalFonts()`)가 목록으로 나오고, 폰트마다 `가나다 Abc` 를 그 폰트로 보여 줍니다. 굵기별 항목은 한 줄로 묶습니다.
    - 줄을 누르면 미리보기 배지가 바뀌고, [적용]하거나 줄을 두 번 누르면 저장합니다.
    - 입력란에 글자를 적으면 이름에 그 글자가 든 폰트만 남습니다(대소문자·띄어쓰기 무시). ↑↓ 로 옮기고 Enter 로 적용합니다. `malgungothic` 처럼 띄어쓰기 없이 적어도 실제 이름(`Malgun Gothic`)으로 저장합니다.
    - 처음 한 번 크롬의 "글꼴" 권한이 필요합니다. 크롬은 확장 프로그램 팝업에서는 권한 창을 띄우지 않고 빈 목록을 돌려주므로(직접 확인), 창의 [새 탭에서 권한 허용하기]가 같은 창을 새 탭 화면에서 엽니다. 거기서 [설치된 폰트 목록 보기] → [허용]을 누르면 그 탭에서 바로 고를 수 있습니다.
    - 한 번 허용하면 다음부터는 팝업에서 창을 열자마자 목록이 나옵니다(권한이 있으면 사용자 조작 없이도 받을 수 있음, 실제 크롬 팝업에서 확인). 처음 한 번은 운영체제가 폰트를 모으느라 몇 초 걸릴 수 있습니다. 목록은 그 화면에만 두고 저장하지 않습니다.
    - 권한을 차단했으면 [크롬 설정 열기]가 이 확장 프로그램의 권한 설정 화면(chrome://extensions 의 [사이트 설정]과 같은 곳)을 엽니다.
  - 목록에 없는 폰트도 이름을 적어 [적용]할 수 있습니다. 미리보기 배지가 그 폰트로 바뀌고, 이 컴퓨터에서 찾았는지 알려 줍니다(같은 글자를 그 폰트와 기본 글꼴로 그려 폭을 비교하는 방식이라, 기본 글꼴과 폭이 똑같은 폰트는 못 찾았다고 나올 수 있음). 찾지 못해도 저장은 됩니다.
  - **파이어폭스**: 설치된 폰트 목록 기능이 없어 목록 없이 이름만 직접 적습니다.
  - 폰트 파일은 넣거나 내려받지 않고 이름만 `'이름', sans-serif` 형태로 저장합니다. X 를 보는 컴퓨터에 그 폰트가 없으면 기본 폰트로 보입니다. 이름에는 따옴표, `\`, 쉼표, `;`, `{ } < >`, 제어 문자를 쓸 수 없고 64자까지입니다. 목록에 있는 폰트와 이름이 같으면(예: `georgia`) 그 폰트로 저장합니다.
  - 백업 파일로 내보내고 가져올 때도 직접 입력한 폰트가 유지됩니다. 이전 버전의 확장 프로그램에서 이 백업을 가져오면 폰트만 기본값이 됩니다.
  - 팝업 [도움말] 탭: [기본 스타일] 묶음을 **기본 스타일과 폰트**로 바꾸고, [설치된 폰트에서 고르기…](처음 한 번 새 탭에서 "글꼴" 권한 허용)와 파이어폭스의 [다른 폰트 직접 입력…]을 적었습니다.
  - 테스트: 단위 테스트 8건(이름 정리·검사, 저장 값, 설치 여부 판단, 폰트 목록 정리, 백업 유지), E2E 10건(공통 설정·리스트 설정 창에서 이름 입력·취소·Enter, 크롬 목록 검색·↑↓·Enter·줄 누르기·두 번 누르기, 권한 미결정 → 새 탭에서 허용, 권한 창을 닫은 경우, 차단 → 설정 화면, **실제 권한을 허용한 상태의 실제 폰트 목록**, 목록이 없는 브라우저, 타임라인 배지 적용), 실제 Firefox 확인 2항목을 추가했습니다.

### 🛠️ Changed (변경 및 개선)
- **"+N" 묶음 규칙과 기본 배지 순서 (`shared/badges.js`)**
  - 보일 배지 수를 설정할 수 있게 되면서, 그 수만큼 배지가 보이고 나머지가 `+N` 으로 묶입니다. 기본값 3개에서 리스트 4개 이상에 속한 사람은 **배지 3개 + `+N`** 으로 보입니다(지금까지는 2개 + `+N`).
  - 순서를 정하지 않은 리스트는 팝업의 이름순과 같은 순서(한국어 정렬: 한글 먼저)로 붙습니다. 지금까지는 브라우저가 저장소에서 돌려주는 순서를 따라서, 크롬에서는 영문 이름이 한글보다 먼저 붙었습니다.
- **팝업 [도움말] 탭을 지금 기능에 맞춰 다시 씀 (`popup.html`)**: 한 묶음이던 "사용 안내"를 **멤버 가져오기 / 배지와 리스트 설정 / 기본 스타일 / 백업 · 문제 해결** 네 묶음으로 나눴습니다. 빠져 있던 [기본 스타일] 탭(화면 테마, 공통 글자 스타일, [모든 리스트에 적용]), 타임라인 표시(강조·흐리게)가 무엇인지, X 에서 바꾼 리스트 이름을 따라가는 것, 팝업을 닫아도 [끝까지 스캔]이 계속되는 것, 백업 가져오기 방식(병합 / 덮어쓰기), 새 탭에서 열기(↗), 배지가 안 보일 때 X 탭 새로고침을 넣었습니다.
  - 테스트: 도움말에 `[이름]` 으로 적은 버튼이 모두 팝업에 실제로 있는지 확인하는 E2E 1건을 추가했습니다(버튼 이름을 바꾸고 도움말을 그대로 두면 실패).

### 📝 Docs (문서)
- **README 사용법을 지금 동작에 맞춤 (`README.md`)**: [도움말] 탭 안내, 리스트 표의 "개별 스타일" 표시, [이 스타일을 모든 리스트에 적용]이 하는 일(공통 설정이 되고 다른 리스트의 개별 스타일을 지움)을 보탰습니다. 백업 가져오기의 **병합**은 "기존 리스트에 멤버만 더함"이라고만 적혀 있었는데, 파일에만 있는 리스트는 새로 추가된다는 것도 적었습니다.
- **README, 개인정보 처리방침 (`README.md`, `docs/PRIVACY.md`)**: 설치된 폰트에서 고르는 방법(처음 한 번 권한 허용 포함)과 자주 묻는 질문(폰트가 적용되지 않을 때)을 README 에 넣었습니다. 개인정보 처리방침에는 저장하는 폰트 값이 이름 하나뿐이라는 것과, 크롬에서 사용자가 "글꼴" 권한을 허용한 경우에만 폰트 창을 여는 동안 설치된 폰트 이름 목록을 읽고 저장하지 않는다는 것을 한국어와 영어로 적었습니다.

## [v1.9.0] - 2026-11-24

### 🚀 Added (새로운 기능)
- **[끝까지 스캔] (`popup/sync.js`, `content.js`, `shared/list-page.js`)**: 팝업의 [현재 탭에서 가져오기] 옆에 **[끝까지 스캔]** 버튼을 추가했습니다. 누르면 X 리스트 멤버 화면을 맨 위로 올린 뒤 끝까지 자동으로 스크롤하며 멤버를 모두 읽고, 끝나면 [뺀 멤버 정리]와 같은 확인 창(지울 멤버·추가될 멤버 수)을 띄웁니다. [교체]를 눌러야 지웁니다.
  - 한 번에 보이는 높이의 60%씩 내리고 0.7초 기다립니다. 앞 구간과 겹치게 내려야 사이의 멤버를 건너뛰지 않았다고 볼 수 있기 때문입니다. X 가 다음 멤버를 불러오는 중이면 기다리고, 목록 끝에 닿은 상태가 2.5초 동안 그대로이면 끝으로 봅니다.
  - 중간을 건너뛰어 이어서 읽지 못하면 맨 위로 돌아가 다시 읽습니다(최대 3번). 15초 동안 아무 변화가 없거나(불러오기 실패 등) 15분이 지나면 멈추고 안내합니다.
  - 스캔하는 동안 팝업 위쪽에 읽은 멤버 수가 보이고 버튼이 **[스캔 중지]**로 바뀝니다. X 화면을 직접 스크롤하거나 누르면 멈춥니다. 팝업이 닫혀도 스캔은 X 탭에서 계속되고, 다시 열면 진행 상황을 이어서 보여 줍니다. 팝업이 닫힌 사이에 스캔이 끝났거나 멈췄다면 다시 열 때 그 결과(끝났으면 확인 창)를 한 번 보여 줍니다.
  - 스캔하는 동안과 끝난 뒤에는 뺀 멤버를 자동으로 지우지 않습니다(확인 창에서 정함). 새 멤버 추가는 예전처럼 자동으로 됩니다.

  - 수정: 크롬용 `extension/manifest.json` 에는 `background.service_worker` 만 둡니다. 파이어폭스 전용 항목(`background.scripts`, `browser_specific_settings`)은 `extension/manifest.firefox.json` 으로 옮겼고, 빌드할 때 합쳐 `dist/firefox/` 를 만듭니다(`npm run build:firefox`, `scripts/build-firefox.js`). 코드 파일은 두 브라우저가 똑같이 씁니다.
  - **배포 zip 이 두 개로 나뉩니다**: `banmo_tag-vX.Y.Z-chrome.zip`(크롬·크롬 계열), `banmo_tag-vX.Y.Z-firefox.zip`(파이어폭스).
  - 파이어폭스 manifest 에서도 쓰지 않는 `background.service_worker` 가 빠져, `web-ext lint` 경고(`BACKGROUND_SERVICE_WORKER_IGNORED`)가 0건이 됐습니다.
  - 정적 검사와 CI 패키징 확인이 크롬 manifest 에 `background.scripts`·`browser_specific_settings` 가 없는지, 파이어폭스 manifest 에 `background.scripts`(순서)·확장 프로그램 ID 가 있는지 확인합니다.
  - 파이어폭스 개발용 설치는 `extension\manifest.json` 대신 `dist\firefox\manifest.json` 을 로드합니다(README 참고).
- **리스트 설정 창에서 배지 색을 직접 고르는 버튼이 보이지 않던 문제 (`popup.html`, `popup.js`)**: 색상 선택 창을 여는 칸이 지금 배지 색을 그대로 칠한 동그라미라서, 빠른 선택 색과 똑같아 보이거나(같은 색일 때) 어두운 점으로만 보였습니다. 이제 **무지개 점 + "다른 색"** 글자가 있는 버튼으로 보이고, 버튼 어디를 눌러도 색상 창이 열립니다. 빠른 선택에 없는 색을 쓰는 중이면 점에 그 색을 보여 주고 선택 표시를 합니다.

## [v1.0.1] - 2026-09-29

### 🚀 Added (새로운 기능)
- **팝업 원클릭 리스트 동기화**: 팝업 상단에 `[⚡ 현재 열린 트위터 리스트 가져오기]` 버튼을 추가하여 현재 활성화된 탭의 리스트를 즉시 스크래핑 및 팝업에 등록할 수 있도록 구현.
- **팝업 내 리스트 수동 직접 등록**: 트위터 페이지를 거치지 않고도 팝업에서 리스트 이름, 멤버 핸들(`@user1, @user2`), 포인트 컬러, 모드(기본/강조/흐리게)를 직접 입력하여 추가할 수 있는 수동 등록 UI 탑재.
- **아코디언 개별 멤버 삭제(`×`) 기능**: 팝업의 리스트를 클릭해 멤버 목록을 펼쳤을 때, 원치 않는 특정 계정만 단독으로 삭제할 수 있는 `×` 버튼 추가.
- **확장 프로그램 아이콘 알림 뱃지**: 새로운 멤버가 수집되거나 리스트가 갱신되면 크롬 우측 상단 아이콘에 파란색 `✔` 뱃지가 표시되어 백그라운드 갱신 상태를 조용하고 직관적으로 인지할 수 있도록 구현 (팝업 열람 시 자동 초기화).

### 🛠️ Changed (변경 및 사용성 개선)
- **트위터 본문 페이지 내 오버레이(알림/플로팅) 전면 제거**: 웹서핑 및 타임라인 탐색을 방해하던 화면 하단 플로팅 버튼(`⚡ 멤버 목록 열기`) 및 하단 중앙 토스트 팝업을 완전히 비활성화하여 트위터 화면 본연의 깔끔하고 쾌적한 UI 유지.
- **다중 시점 자동 스크래핑**: 페이지 초기 로딩 시 스크롤을 하지 않아도 0ms, 500ms, 1500ms, 3000ms 간격으로 자동 스캔을 실행하여 짧은 리스트나 정적인 화면에서도 안정적으로 수집되도록 개선.

### 🐛 Fixed (버그 수정)
- **멤버 모달 창(`role="dialog"`) 엄격 격리**: 리스트 구성원 관리 모달 창이 열렸을 때, 창 뒤편 배경의 타임라인이나 우측 사이드바에 렌더링된 "팔로우 추천(Who to follow)" 유저가 리스트 멤버로 잘못 섞여 들어가는 문제를 100% 원천 차단.
- **추천(Suggested) 섹션 자동 필터링**: `팔로우 추천`, `Who to follow`, `추천 사용자`, `Suggested` 라벨/헤딩이 지정된 컨테이너 및 사이드바(`sidebarColumn`, `aside`)의 유저 셀 자동 제외.
- **리스트 이름 내 태그/핸들(`@username`) 자동 정제**: 트위터 브라우저 타이틀이나 헤더에 기본으로 덧붙여지던 `(@username)`, `· @username`, `by @username` 등을 자동 감지하여 순수한 리스트 이름만 추출되도록 정제 로직(`cleanListName`) 및 기존 저장 데이터 자동 마이그레이션(`sanitizeListsObject`) 적용.
- **스토리지 무한 루프 및 스로틀링 해결**: 멤버 목록에 실질적 변경이 없을 때는 `chrome.storage.local.set`을 호출하지 않도록 방어 로직을 적용하여 브라우저 버벅임 방지.

## [v1.0.0] - 2026-09-29

### 🚀 Added (새로운 기능)
- **기본 프로젝트 및 Manifest V3 구조 설정**: 최신 크롬 확장 프로그램 표준(Manifest V3) 기반 서비스 워커 및 콘텐츠 스크립트 뼈대 생성.
- **리스트 멤버 자동 스크래핑(캐싱)**: 리스트 멤버 페이지 방문 시 화면에 렌더링된 유저 핸들을 백그라운드에서 자동 수집 및 로컬 스토리지에 중복 없이 캐싱.
- **타임라인 인라인 배지 렌더링**: 리스트 멤버가 트윗 작성 시 닉네임 바로 옆에 둥근 형태의 리스트 배지 주입 (가로 정렬, 글자 폭 자동 맞춤, 줄바꿈 방지 UI 최적화).
- **인용 트윗 및 스레드용 미니 배지(Mini-Badge)**: 본문 작성자뿐만 아니라 인용 트윗(Quote) 및 답글 스레드 작성자에게도 축소된 미니 뱃지 주입.
- **강조 & 흐림 모드(Highlight & Dim)**:
  - 강조(Highlight): 트윗 카드 좌측에 4px 포인트 컬러 테두리 생성.
  - 흐리게(Dim): 관심도가 낮은 리스트 멤버의 트윗 투명도를 50%(`opacity: 0.5`)로 낮춰 피로도 완화.
- **팝업 관리 UI (`popup.html`)**:
  - 리스트별 배지 배경색 커스터마이징 (Color Picker).
  - 아코디언 형태로 수집된 멤버 목록 확인.
  - 개별 리스트 삭제 및 전체 데이터 일괄 초기화 기능.
- **설정 백업 및 복원 (Export / Import)**: 리스트 매핑 데이터, 모드, 컬러 설정을 JSON 파일로 다운로드 및 복구할 수 있는 도구 탑재.

### 🐛 Fixed (버그 수정)
- **페이지 타이틀 기반 리스트명 추출 분리**: 모든 리스트가 '리스트 멤버'라는 단일 이름으로 합쳐지던 현상을 방지하기 위해 고유 리스트명을 식별하도록 수정.
- **사이드바 영역 분리 1차 적용**: 사이드바의 팔로우 추천 유저들이 메인 리스트로 유입되지 않도록 1차 `primaryColumn` 한정 적용.
