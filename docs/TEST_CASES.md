# banmo_tag 테스트 케이스

banmo_tag 가 무엇을 어떻게 테스트하는지 정리한 문서입니다.

- 버전마다 테스트를 돌린 결과는 [TEST_RESULTS.md](TEST_RESULTS.md)에 기록합니다.
- 기능 변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

| 종류 | 무엇을 확인하나 | 명령 | CI |
|---|---|---|:-:|
| 정적 검사 | manifest, 파일 참조, 금지 코드, 문서 링크 | `npm run validate` | ✅ |
| ESLint | 문법, 정의 안 된 함수(`shared/` 의 함수 이름 변경) | `npm run lint` | ✅ |

| E2E | 실제 확장 프로그램을 Chromium 에 넣고 팝업·X 화면 동작 | `npm test` | ✅ |

## 실행 방법

### 한 번에 실행하고 결과 기록하기

```powershell
npm run test:report -- --firefox            # 모든 자동 검사 실행, 결과를 화면에 출력
npm run test:report -- --firefox --write    # 결과를 docs/TEST_RESULTS.md 맨 위에 기록
```

- 결과 제목은 자동으로 정합니다. CHANGELOG `[Unreleased]` 에 항목이 있으면 `Unreleased`, 없으면 `v<manifest 버전>` 입니다.
  - 직접 정하려면 `--label v1.8.0` 을 붙입니다.
  - 같은 제목의 결과가 이미 있으면 새 결과로 바꿉니다.
- `--firefox` 를 빼면 실제 Firefox 확인은 "실행 안 함" 으로 기록됩니다.
- 수동 확인 표는 빈칸으로 만들어지니, 직접 확인한 뒤 결과를 채웁니다.

### 하나씩 실행하기

| 명령 | 내용 |
|---|---|
| `npm run check` | 정적 검사 → ESLint → Firefox 호환성 → E2E(단위 테스트 포함) |
| `npm test` | E2E 만 (처음 한 번 `npm ci`, `npx playwright install chromium`) |
| `npm run test:firefox` | 실제 Firefox 확인 |
| `powershell -ExecutionPolicy Bypass -File tests\run-tests.ps1` | 단위 테스트만 (설치된 Chrome/Edge headless, Node.js 불필요) |
| `tests\test-runner.html` 을 브라우저로 열기 | 단위 테스트 결과를 화면으로 보기 |
| `scripts\build.ps1` | 버전 확인 → 정적 검사·ESLint → 단위 테스트 → 배포 zip |

- GitHub Actions(`.github/workflows/ci.yml`)는 main push 와 모든 PR 에서 다음을 실행합니다. Release 와 배포 파일은 만들지 않습니다.
  - 정적 검사·ESLint·Firefox 호환성
  - E2E (Ubuntu)
  - 실제 Firefox
  - 단위 테스트와 zip 패키징 확인 (Windows)

## 수동 확인 시나리오

로그인한 실제 X 화면에서 확인합니다.

- 크롬: `chrome://extensions` 에서 `extension` 폴더를 로드합니다.
- Firefox: `npm run firefox:live` 와 `npm run firefox:run` 을 씁니다. 사용법은 [DEVELOPMENT.md](DEVELOPMENT.md#테스트) 의 "실제 x.com 에서 Firefox 확인" 에 있습니다.

결과는 [TEST_RESULTS.md](TEST_RESULTS.md)의 그 버전 표에 적습니다.

### [M-01] 리스트 이름에 내 아이디가 붙지 않음
- **사전 조건**: 내가 만든 리스트(예: `코인 뉴스`)가 있음
- **절차**: 그 리스트의 멤버 화면을 열고 팝업에서 [현재 탭에서 가져오기]를 누른다.
- **기대 결과**: 리스트 이름이 `코인 뉴스 (@내아이디)` 가 아니라 `코인 뉴스` 로 저장되고, 타임라인 배지에도 `코인 뉴스` 만 보인다.

### [M-02] 멤버 창 뒤의 "팔로우 추천" 계정은 수집하지 않음
- **절차**: 리스트 멤버 창(`role="dialog"`)을 연 상태에서 팝업의 [현재 탭에서 가져오기]를 누르고, 리스트 줄을 눌러 [멤버 N명 보기]로 멤버를 본다.
- **기대 결과**: 창 안의 멤버만 저장되고, 창 뒤 타임라인이나 오른쪽 사이드바의 추천 계정은 하나도 없다.

### [M-03] "구성원" 탭에서만 자동 수집
- **절차**:
  1. 리스트 멤버 관리 창의 "구성원" 탭에서 스크롤한다.
  2. "추천(Suggested)" 탭으로 바꿔 스크롤한 뒤 [현재 탭에서 가져오기]를 누른다.
- **기대 결과**: "구성원" 탭에서는 멤버가 저장된다. "추천" 탭에서는 저장되지 않고, `"추천" 탭에서는 수집하지 않습니다.` 안내가 뜬다.

### [M-04] 리스트 메인 → 멤버 화면 이동 시 실제 이름 사용
- **절차**: 리스트 메인(`/i/lists/<ID>`)을 연 뒤 "N 멤버"를 눌러 멤버 화면으로 이동한다.
- **기대 결과**: 임시 이름 `리스트 (<ID>)` 가 아니라 실제 리스트 이름으로 저장된다.

### [M-05] 수집 알림 (확장 프로그램 아이콘 ✔)
- **절차**: 멤버 창을 스크롤해 새 멤버가 저장되게 한 뒤 툴바의 banmo_tag 아이콘을 보고, 아이콘을 눌러 팝업을 연다.
- **기대 결과**: 새 멤버가 저장되면 아이콘에 `✔` 표시가 붙고, 팝업을 열면 사라진다.

### [M-06] X 화면에 떠 있는 버튼·알림 없음
- **절차**: 리스트 화면과 타임라인을 스크롤하고 새로고침한다.
- **기대 결과**: 화면 아래쪽에 banmo_tag 의 버튼이나 알림(토스트)이 나타나지 않는다.

### [M-07] 타임라인 배지 · 강조 · 인용 미니 배지
- **절차**: 리스트 멤버가 쓴 트윗과, 리스트 멤버의 트윗을 인용한 트윗을 찾는다. 타임라인을 길게 스크롤한다.
- **기대 결과**:
  - 이름 옆에 리스트 배지가 붙고, 강조 모드 리스트는 트윗 왼쪽에 색 띠가 보인다.
  - 인용 카드 작성자 이름 옆에는 작은 배지가 붙는다.
  - 스크롤해서 새로 나온 트윗에도 배지가 붙고, 다른 사람 트윗에 이전 배지가 남지 않는다.

### [M-08] 배지 많을 때 +N · 긴 이름 말줄임 · 흐리게 모드
- **사전 조건**: 한 사람을 리스트 4개 이상에 넣고, 이름이 긴 리스트 하나와 흐리게 모드 리스트 하나를 만든다.
- **절차**: 그 사람의 트윗에서 `+N` 과 긴 이름 배지에 마우스를 올리고, 흐리게 모드 리스트 멤버의 트윗을 본다.
- **기대 결과**:
  - 배지는 3개와 `+N` 만 보이고(보일 배지 수 기본값), `+N` 툴팁에 "banmo tag 리스트 N개: …" 로 모든 리스트 이름이 보인다.
  - 긴 이름은 `…` 으로 줄고, 툴팁에 전체 이름이 보인다.
  - 흐리게 모드는 프로필 사진·본문·사진만 흐리고, 이름과 배지는 또렷하다.

### [M-09] 배지 글자 스타일이 타임라인에 바로 반영
- **절차**:
  1. 팝업 [기본 스타일] 탭에서 글자 색을 `#ffff00`, 크기를 `16px`, 폰트를 `Monospace` 로 바꾼다.
  2. 타임라인을 본 뒤 [기본값]을 누른다.
  3. 리스트 줄을 눌러 그 리스트만 글자 크기를 다르게 정한다.
- **기대 결과**:
  - 타임라인 배지가 새로고침 없이 바뀐다(인용 미니 배지는 2px 작게).
  - [기본값]이면 흰 글자·11px·시스템 폰트로 돌아간다.
  - 리스트별 설정은 그 리스트 배지에만 적용된다.

### [M-10] 팝업에서 리스트 관리
- **절차**:
  1. [+ 추가]로 `테스트 리스트` 와 멤버 `@testuser1` 을 저장한다.
  2. 리스트 줄을 눌러 배지 색과 타임라인 표시(배지만/강조/흐리게)를 바꾼다.
  3. [이름 바꾸기]로 이름을 바꾼다. X 에서 가져온 리스트의 이름도 하나 바꾼 뒤, 그 리스트의 멤버 화면을 다시 연다.
  4. [멤버 N명 보기]에서 멤버 하나를 `×` 로 지운다.
  5. [리스트 삭제]로 리스트를 지운다.
  6. 지운 리스트를 X 에서 다시 가져온다.
- **기대 결과**:
  - 바꾼 내용이 바로 리스트 표와 타임라인에 반영된다.
  - 이름을 바꿔도 배지 색·표시 방식·멤버는 그대로이고, 타임라인 배지에 새 이름이 보인다. 직접 바꾼 이름은 멤버 화면을 다시 열어도 X 이름으로 돌아가지 않는다.
  - 삭제 전에는 팝업 안 확인 상자가 뜬다(브라우저 기본 대화상자가 아님).
  - 지운 리스트는 다시 가져오면 정상으로 다시 등록된다.

### [M-11] 뺀 멤버 정리
- **절차 (자동)**:
  1. X 에서 리스트 멤버 한 명을 뺀다.
  2. 그 리스트의 멤버 화면을 열고 맨 위부터 끝까지 천천히 스크롤한 뒤 3초쯤 기다린다. (멤버가 한 화면에 다 보이면 열어 두기만 한다.)
- **기대 결과 (자동)**: 뺀 멤버가 저장된 목록에서 지워지고(팝업의 멤버 수가 줄어듦), 확장 프로그램 아이콘에 ✔ 가 잠깐 보인다. 다른 멤버, 배지 색, 표시 방식은 그대로다.
  - 멤버가 많은 리스트(스크롤해야 다 보이는 리스트)에서도 끝까지 내리면 지워지는지, 중간까지만 내리면 지워지지 않는지 확인한다.
  - 팝업 [+ 추가]로 그 리스트에 직접 더한 멤버는 지워지지 않는다.
- **절차 (직접)**:
  1. 멤버 화면을 끝까지 스크롤한다.
  2. 팝업의 [뺀 멤버 정리]를 누른다.
- **기대 결과 (직접)**: 지울 멤버가 있으면 확인 상자에 보이고, [교체]를 누르면 그 멤버만 지워진다. 이미 최신이면 확인 없이 안내만 뜬다.

### [M-12] 백업 내보내기 · 가져오기 (병합 / 덮어쓰기)
- **절차**:
  1. ⋯ 메뉴의 [백업 파일로 내보내기]로 파일을 저장한다.
  2. 다른 리스트를 만든 뒤 [백업 파일 가져오기]로 그 파일을 고르고 [병합]을 누른다.
  3. 한 번 더 가져오고 이번에는 [덮어쓰기]를 누른다.
- **기대 결과**:
  - 병합하면 기존 리스트와 파일의 리스트가 모두 남는다.
  - 덮어쓰면 파일 내용(배지 설정 포함)으로 바뀐다.
  - Firefox 팝업에서는 내보내기·가져오기가 새 탭 화면에서 열린다.

### [M-13] 화면 테마 (시스템 / 라이트 / 다크)
- **절차**:
  1. 운영체제를 다크 모드로 두고 팝업을 연다.
  2. [기본 스타일] 탭에서 `라이트` 를 고른다.
  3. 팝업을 닫았다 다시 연다.
  4. `시스템` 으로 되돌린다.
- **기대 결과**:
  - 처음에는 어둡게 열린다.
  - `라이트` 를 고르면 바로 밝아지고, 다시 열어도 처음부터 밝다(어두운 화면이 잠깐 보이지 않음).
  - `시스템` 으로 되돌리면 다시 운영체제 설정을 따른다.
  - 두 테마 모두 글자와 버튼이 또렷하다.

### [M-14] 새 탭 화면 · Firefox 팝업 우회 · x.com 접근 권한
- **절차**:
  1. X 탭에서 팝업의 [↗]로 새 탭 화면을 연다.
  2. 그 화면에서 [현재 탭에서 가져오기]를 누른다.
  3. Firefox 에서는 리스트 설정 창의 "다른 색"을 누른다.
- **기대 결과**:
  - 새 탭 화면의 가져오기는 원래 보던 X 탭을 대상으로 동작한다.
  - Firefox 에서는 같은 리스트의 설정 창이 열린 새 탭 화면이 뜬다.
  - x.com 접근을 허용하지 않았다면 팝업에 안내와 [x.com 접근 허용] 버튼이 보인다.

### [M-15] X 화면 구조 변화 경고가 잘못 뜨지 않음
- **절차**: 홈 타임라인과 리스트 멤버 화면을 평소처럼 쓴 뒤 팝업을 연다.
- **기대 결과**: 정상 화면에서는 "X 화면 구조가 바뀌었을 수 있습니다" 경고가 뜨지 않는다.

### [M-16] 배지 순서 · 타임라인 배지 표시 설정 (⚙)
- **사전 조건**: 한 사람을 리스트 4개 이상에 넣고(그중 하나는 이름이 길게, 하나는 강조 모드), 다른 사람을 흐리게 모드 리스트에 넣는다.
- **절차**:
  1. 팝업 오른쪽 위 ⚙ 를 눌러 설정 창을 열고, 배지 순서에서 맨 아래 리스트를 ▲ 로 맨 위까지 올린다. 다른 줄은 끌어서 옮겨 본다.
  2. 보일 배지 수를 1개로, 그다음 모두로 바꾼다.
  3. 긴 이름 줄이기를 끄고, 배지 모양을 각지게, 인용 트윗 작성자 배지를 끔, 흐리게 정도를 진하게로 바꾼다.
  4. [이름순으로 되돌리기]와 [표시 설정 기본값]을 누른다.
- **기대 결과**:
  - 타임라인 배지가 새로고침 없이 배지 순서대로 붙고, 넘친 리스트는 순서가 뒤인 것부터 `+N` 으로 묶인다. 강조 색 띠는 순서가 앞인 강조 리스트의 색이다.
  - 보일 배지 수 1개면 배지 1개 + `+N`, 모두면 `+N` 없이 전부 보인다.
  - 말줄임을 끄면 긴 이름이 다 보이고, 모서리가 각지고, 인용된 트윗 작성자의 작은 배지가 사라지고, 흐리게 리스트 멤버의 본문이 더 흐려진다.
  - 설정 창의 미리보기와 팝업 리스트 표의 배지 모양이 같은 설정을 따른다.
  - 되돌리면 이름순, 기본값(3개, 말줄임 켬, 둥글게, 인용 배지 켬, 보통)으로 돌아간다.
